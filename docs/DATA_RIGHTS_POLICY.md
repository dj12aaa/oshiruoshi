# OSHIRU データ・画像利用ポリシー（開発判断用）

> これは開発チーム向けの安全基準であり、個別案件についての法律上の保証ではない。公開・収益化規模が大きくなる前に必要に応じて専門家レビューを行う。

## 公開可否の基本ルール

### A. 原則表示可能候補
- OSHIRU自身が作成した文章・UI・アイコン
- 事実データとして取得した商品価格・日時等（取得元の利用規約/API条件も別途確認）
- 公式API/許諾済みフィードが明示的に提供し、表示条件を満たす画像URL
- 利用者本人がアップロードし、画像検索処理のため一時的に利用する画像

### B. 条件確認が必要
- メーカーの商品画像
- EC/フリマの商品画像
- キャラクター/作品のキービジュアル
- SNS投稿画像
- アフィリエイト用画像

API/アフィリエイト規約、権利者ガイドライン、クレジット条件、保存/キャッシュ可否を確認する。

### C. 公開しない
- 出品者画像をOSHIRUサーバーへ無断コピーして恒久保存
- 「ネットで拾った画像」の転載
- 公式と誤認させるロゴ/デザイン/ドメイン
- 権利状態が不明な画像を「引用だから大丈夫」と一律判断して大量掲載

## 商品カードの安全な優先順位
1. 許諾済み/API画像
2. OSHIRUの中立プレースホルダー
3. タイトル・価格・販売元・確認日時
4. 販売元の個別ページへのリンク

画像がなくても検索サービスとして成立するように設計する。

## データの表示
- 取得元を表示
- 最終確認日時を表示
- 送料不明は「不明」
- 在庫/販売状態を推測しない
- AIによる商品同一判定は「候補」「推定」と表示
- 販売元での最終確認CTAを維持

## 画像検索
ユーザー画像は「検索語抽出」の入力として扱う。
- 永続保存は原則しない
- ログへ画像本体を出さない
- 外部AIへ送信する場合は事前にプライバシーポリシーへ記載
- 画像から抽出した検索語だけを通常の商品検索へ渡す

## アフィリエイト/広告
- 広告・PR・アフィリエイトであることを視認可能な場所に表示
- 広告案件によって検索順位/比較順位を不透明に変更しない
- スポンサー枠を入れる場合は通常検索結果と視覚的に区別

## リリースチェック
- [ ] 各画像の取得根拠を説明できる
- [ ] API利用規約/クレジット要件を確認済み
- [ ] 公式サービスと誤認する表示がない
- [ ] 商品価格/在庫/送料の取得時刻が分かる
- [ ] 削除要請の問い合わせ窓口がある
- [ ] プライバシーポリシーが実装と一致している

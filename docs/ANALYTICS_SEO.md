# OSHIRU 無料計測・SEO公開手順

## 開発中
- `develop-v2` は `noindex,nofollow`
- Production `main` は一般公開停止を維持
- Search Consoleにはまだ公開版を送信しない

## 公開直前
1. 独自ドメインを確定
2. 公開版のcanonicalを独自ドメインへ統一
3. `robots`を公開対象ページのみ `index,follow` に変更
4. sitemap.xmlへ公開対象URLだけ入れる
5. 0件検索、404、ユーザー固有ページ、薄い検索結果ページはnoindex
6. Google Search Consoleで所有権確認
7. sitemap.xmlを送信
8. URL検査でトップ/作品ページ/キャラページを確認

## 無料で見る指標

### Search Console
目的: Google検索からの流入確認
- 表示回数
- クリック
- CTR
- 平均掲載順位
- 検索クエリ
- インデックス状態

### Vercel Web Analytics
目的: 軽いページビュー/参照元/デバイス確認
- 初期βではこれを最初のアクセス計測に使う
- Hobby上限に近づいたらUsageを確認

### GA4
導入タイミング:
- `search`
- `outbound_product_click`
- `favorite_add`
- `saved_search_add`
- `image_search_start`
などの行動イベントを詳しく見たくなったとき。

GA4導入前にプライバシーポリシーと同意/識別子の扱いを確認する。

## OSHIRUで毎週確認するKPI
- WAU
- 検索回数/利用者
- 0件検索率
- 販売元クリック率
- お気に入り追加率
- 保存検索率
- 再訪率
- モバイル比率
- 検索語上位20件
- 0件検索語上位20件
- コラボ別検索数
- グッズ種別別クリック率

## 増えていない原因の切り分け

### 表示回数が少ない
SEO/認知の問題。
- 固定URLの作品/キャラ/コラボページを作る
- sitemap/内部リンクを改善
- SNSで検索可能な具体例を共有

### 表示回数はあるがCTRが低い
検索結果タイトル/説明が弱い。
- titleを検索意図に合わせる
- 「価格比較」「販売中」「横断検索」など提供価値を明示

### 来訪はあるが検索されない
ファーストビュー/検索UIの問題。
- 検索欄を最優先
- 例検索を改善
- 検索できる対象を明確化

### 検索されるが販売元クリックが少ない
検索精度/比較価値の問題。
- 0件・無関係結果を減らす
- 総額/送料/状態を見やすくする
- 同一商品の重複整理

### 初回利用はあるが再訪しない
継続価値の問題。
- 保存検索
- お気に入り
- 新着通知
- 推し登録
の順で強化する。

## β版の集客
有料広告より先に無料導線を検証する。
- Xで「作品名 + グッズ種別 + 比較例」の短い動画/画像
- 推し活コミュニティでテスト利用者を募集（各コミュニティ規約順守）
- 作品/キャラ/コラボごとの検索可能ページを作る
- 「○○ アクスタ 相場」「○○ グッズ どこで買える」など検索課題に答えるガイド
- 友人/テスターに5分の操作テストを依頼し、迷った箇所を記録

大量のSEO記事をAIで量産するのではなく、検索結果/価格比較/在庫探索というOSHIRU固有価値があるページを増やす。
